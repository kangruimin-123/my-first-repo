# AI 工具申请审批流程 V1 - 表单字段说明

## 1. 基础信息

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| 申请人 | 自动带出 | 是 | 默认当前提交人 |
| 所属部门 | 自动带出 | 是 | 同时作为默认成本归属部门 |
| 岗位 / 职位 | 自动带出 / 可选 | 建议 | 用于审批信息汇总 |
| 直属领导 | 自动带出 | 是 | 用于直属领导审批 |
| 期望生效日期 | 日期 | 是 | 希望开通、续费、变更或停用的日期 |
| 申请原因简述 | 多行文本 | 是 | 简要说明为什么申请 |

> 注意：不设置「成本归属」字段。成本归属默认取申请人所属部门。

## 2. 资源类型与申请事项

| 字段 | 类型 | 是否必填 | 选项 |
|---|---|---:|---|
| 资源类型 | 单选 | 是 | API Key / 接口额度；订阅账号 / 席位；共享账号 / 公共资源；其他 AI 工具资源 |
| 申请事项 | 单选 | 是 | 新增；续费 / 续期；增额 / 增购；变更；停用 / 回收；其他 |

## 3. API Key / 接口额度字段（条件展示）

当 `资源类型 = API Key / 接口额度` 时展示。

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| API Key 工具 | 多选 | 是 | API Key 可多选 |
| 关联项目 | 文本 | 是 | 由申请人自定义填写 |
| 预估额度 | 文本 / 数字 | 否 | 参考信息，用户不清楚可不填 |
| 开始使用时间 | 日期 | 是 | 使用周期开始时间 |
| 结束使用时间 | 日期 | 是 | 使用周期结束时间 |
| 申请事项补充说明 | 多行文本 | 条件必填 | 增额、续期、变更、停用时填写原因 |
| 备注 | 多行文本 | 否 | 补充费用、特殊原因或其他说明 |

API Key 分支不展示：`平台模型`、`后台调用量查看`、`负责人`、`成本负责人`、`成本归属`。

默认规则：
- API Key 负责人 = 申请人
- API Key 成本负责人 = 申请人
- 成本归属部门 = 申请人所属部门

## 4. 订阅账号 / 席位字段（条件展示）

当 `资源类型 = 订阅账号 / 席位` 时展示。

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| 订阅工具 | 单选 | 是 | 订阅类工具只能单选 |
| 工具类型 | 单选 | 是 | 通用大模型、代码辅助、图像生成、音频生成等 |
| 拟申请 / 当前订阅套餐 | 文本 / 单选 | 是 | 新增时填写拟申请套餐，续费时填写当前套餐 |
| 席位数量 | 数字 | 是 | 本次申请的独立账号 / 席位数量 |
| 使用人 | 人员选择 | 是 | 订阅账号实际使用人 |
| 订阅周期 | 单选 / 日期 | 是 | 1个月、3个月、6个月、1年、自定义 |
| 当前到期时间 | 日期 | 续费时必填 | 用于续费判断 |
| 续费 / 增费依据 | 多行文本 / 附件 | 续费、增额、增购时必填 | 说明历史使用情况、业务必要性或费用变化原因 |
| 变更前使用人 | 人员选择 | 变更时必填 | 原使用人 |
| 变更后使用人 | 人员选择 | 变更时必填 | 新使用人 |
| 停用 / 回收对象 | 人员 / 文本 | 停用时必填 | 停用账号或席位 |

## 5. 共享账号 / 公共资源字段（条件展示）

当 `资源类型 = 共享账号 / 公共资源` 时展示。

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| 共享工具 / 资源名称 | 单选 / 文本 | 是 | 共享账号或公共资源名称 |
| 共享申请方式 | 单选 | 是 | 新建共享账号；申请使用已有共享账号；变更共享账号；续费共享账号；停用共享账号 |
| 共享账号责任人 | 人员选择 | 是 | 默认申请人，可修改 |
| 共享人 | 多人员选择 | 是 | 共享账号实际使用人 |
| 使用范围 | 单选 / 文本 | 是 | 小组、部门、指定人员、跨部门等 |
| 使用期限 | 日期 / 周期 | 是 | 明确使用到期时间 |
| 是否已有共享账号 | 单选 | 申请使用已有账号时必填 | 是 / 否 / 不确定 |
| 变更内容 | 多行文本 | 变更时必填 | 说明变更前后差异 |
| 停用 / 回收原因 | 多行文本 | 停用时必填 | 说明停用原因 |

## 6. 使用场景字段（全资源类型）

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| 使用场景分类 | 单选 / 多选 | 是 | 按场景分类选择 |
| 具体使用说明 | 多行文本 | 是 | 说明实际业务用途 |
| 使用人范围 | 单选 / 文本 | 是 | 仅本人、小组、部门、指定人员等 |
| 使用频率 | 单选 | 是 | 每日、每周、每月、临时、其他 |
| 使用周期 | 日期 / 单选 | 是 | 开始时间、结束时间或固定周期 |

使用场景分类：代码辅助、图像生成、音频生成、视频生成、文本写作、数据分析、办公效率、翻译润色、客服 / 知识库、自动化流程、学习研究、其他。

> 工具链接字段去掉，不要求申请人填写。

## 7. 费用与备注字段（全资源类型）

| 字段 | 类型 | 是否必填 | 规则 |
|---|---|---:|---|
| 预计月成本 | 金额 | 建议 | 人民币，用户自行填写；无法预估可填 0 |
| 预计年成本 | 金额 | 建议 | 人民币，用户自行填写；按年订阅建议填写 |
| 备注 | 多行文本 | 否 | 费用说明、特殊原因、补充信息统一写入备注 |

费用规则：
1. 费用类型默认 = AI 费用，不需要用户填写。
2. 币种默认 = 人民币，不需要用户选择。
3. 成本归属部门默认 = 申请人所属部门，不需要用户填写。
4. 费用说明统一放入备注。
5. 表单中不要出现「成本归属」字段。
