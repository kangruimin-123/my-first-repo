# 产品交付物

## 定位

产品是场景边界的定义者。产品告诉系统用户会怎么问、每种问法期望什么行为、哪些必须拒绝。

## 交付物 1：用户场景表

阶段 B 之前交付。

| 用户原话 | 期望行为 | 期望路由 | 优先级 |
|---|---|---|---|
| 苍蓝昨天收入多少 | 返回收入数字 | query_from_config | P0 |
| 苍蓝昨天收入为什么跌 | 返回诊断结论 | agent_fallback | P0 |
| 帮我总结这张表 | 用已有数据生成总结 | messages_route | P0 |
| 昨天投放日报 | 返回预制报表 | prebuilt_report | P0 |
| 看一下苍蓝大盘 | 返回看板快照 | dashboard_route | P0 |
| 用户 xxx 的充值记录 | 拒绝 | reject | P0 |
| 苍蓝注册到首充的漏斗 | 返回漏斗分析 | analysis_template | P1 |
| 帮我做个周报 | 生成周报 | workflow_route | P1 |
| 你好 | 闲聊回复 | chat | P2 |
| 帮我改数据库 | 拒绝 | reject | P0 |

要求：第一阶段至少 10 条 P0 场景、5 条 P1 场景。

## 交付物 2：拒绝场景清单

阶段 C 之前交付。

| 触发条件 | 拒绝理由 | 回复话术建议 |
|---|---|---|
| 问 user_id / device_id / openid / ip | 敏感字段 | 出于数据安全，无法查询个人标识信息 |
| 要求直接写 SQL | 不支持 | 我无法直接执行 SQL，请描述你的分析需求 |
| 项目不存在 | 无法识别 | 请确认项目名称，目前支持苍蓝和文明重启 |
| 问非数据分析问题 | 超出范围 | 我是数据分析助手，这个问题超出了我的能力范围 |

## 交付物 3：回答质量标准

阶段 D 之前交付。

| 维度 | 要求 |
|---|---|
| what | 回答了什么事实，必须有数字 |
| so_what | 这个事实意味着什么，必须有判断 |
| why | 为什么这样，必须有归因或说明数据来源 |
| next | 建议下一步看什么，必须有可操作建议 |
